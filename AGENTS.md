## 📋 Mandatory Agent "Definition of Done" (DoD) Protocol

Whenever you perform work in this repository, you **MUST** complete these synchronization steps before concluding your turn:

1. **Route Modified or Added?**
   - Update [`docs/SITEMAP.md`](file:///./docs/SITEMAP.md) with the new route, component, and database bindings.
   - Run `npm run docs:verify` to confirm zero discrepancies.

2. **Database Table / Schema Changed?**
   - Update [`docs/DATABASE.md`](file:///./docs/DATABASE.md) and [`src/types/database.ts`](file:///./src/types/database.ts).

3. **Feature Milestone Completed?**
   - Bump version in `package.json` and [`src/config/version.ts`](file:///./src/config/version.ts) (e.g., `1.0.0` → `1.0.1` or `1.1.0`).
   - Add a brief entry in [`CHANGELOG.md`](file:///./CHANGELOG.md).
   - Update the **Current Version** and **Last Updated** badge at the top of `AGENTS.md`.

4. **AI Discovery & SEO Manifests Maintained?**
   - If public offerings, pages, or content models changed, run `npm run catalog:sync` to regenerate `public/llms.txt`, `public/llms-full.txt`, `public/robots.txt`, and `public/sitemap.xml`.

5. **Health Check Passed?**
   - Run `npm run typecheck` (zero TypeScript compiler errors).
   - Run `npm run dod:check` to verify all quality gates.
